# Köprü 🌉

**Referansla iş bulmayı kolaylaştıran, gönüllülük esaslı bir dayanışma ağı.**

Köprü, öğrencilerin ailelerinde ve çevrelerinde çalışan kişileri (anne, baba, abla, abi, tanıdıklar) gönüllü **referans** olarak ağa katmasını sağlar. İş arayan kişi yalnızca **sektör ve pozisyon** seçer. Sistem uygun referansa "böyle bir aday var" diye haber verir. Referans ilgilenirse adayın CV'sini görür ve aradaki tanıdıklık bağı üzerinden iletişim kurulur.

> Sahte ilanlar ve uzun süreçler yerine: doğrudan, tanıdık üzerinden, referanslı başvuru.

> **Not:** "Köprü" çalışma adıdır. Kalıcı isim ekip oylamasıyla belirlenecektir.

## Durum

🟡 **Analiz ve tasarım aşaması.** Kod yazmaya hocamızın analiz onayından sonra başlıyoruz.

| Aşama | Durum |
|---|---|
| 1. Gereksinim analizi (fonksiyonel / fonksiyonel olmayan) | 🟡 Devam ediyor |
| 2. Use case şeması ve aktörler | ⚪ Bekliyor |
| 3. Arayüz taslakları (wireframe) | ⚪ Bekliyor |
| 4. Teknik planlama (stack, veritabanı, hosting) | ⚪ Bekliyor |
| 5. Geliştirme ve test | ⚪ Bekliyor |
| 6. Yayına alma ve tanıtım | ⚪ Bekliyor |

## İlkeler

- **Gönüllülük:** Ticari amaç yok, reklam yok, ücret yok.
- **Önce rıza:** Kimsenin verisi izni olmadan sisteme girmez (KVKK).
- **Önce referans:** v1 yalnızca referanslı başvuru. İş ilanı panosu değiliz.
